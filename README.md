# Bookstore_frontend

Книжный интернет-магазин созданный на базе React.p

## Функционал

- Каталог книг с фильтрацией
- Корзина 
- Оформление заказа (форма доставки + имитация оплаты)
- Личный кабинет (редактирование профиля)
- Избранное
- История заказов

---

| **Frontend** |
|--------------|
| React 18 |
| React Router v6 |

| React Icons |

## Запуск локально

### 1.Установка pnpm 
```bash

npm install -g pnpm

```

### 2.Установка зависимостей
```bash
pnpm install
```
### 3.Запуск проекта 
```bash
pnpm run dev
```
